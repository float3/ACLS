# ACLS

Toon shader for Unity's built-in render pipeline with AudioLink support. Shaders appear under `ACiiL/toon/` as solid, cutout, alpha, dithered and outline variants, plus depth-only helpers. `Editor/ACLSInspector.cs` supplies the material inspector.

## Install

Copy this folder anywhere inside `Assets/`. AudioLink is optional; `ACLS_AudioLink.cginc` picks it up when the AudioLink package is present.
